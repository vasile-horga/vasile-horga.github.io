# Vasile Horga — academic website

Static website for GitHub Pages. Files:
- `index.html` — page structure and text
- `style.css` — responsive visual design
- `script.js` — search/filter and rendering
- `publications.js` — publications, books, patents and awards parsed from the supplied list

## Publish
1. In the `vasile-horga.github.io` repository, choose **Add file → Upload files**.
2. Upload all four website files from this folder to the repository root (not the ZIP itself).
3. Commit the files to `main`.
4. In **Settings → Pages**, choose **Deploy from a branch**, branch `main`, folder `/(root)`, then Save if this is not already selected.
5. Open `https://vasile-horga.github.io/` after deployment completes.

The site intentionally has no portrait and no invented email address. Research topics are summarized from the supplied publication list. The source contains entries from several years but not necessarily every numbered item.
